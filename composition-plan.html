Element Content purpose Normal-flow baseline Chosen technique and why Containing block / stacking context Fallback or disengagement Required test
.pull-quote Emphasis on quoted text Appears between paragraphs Edited margin-inline-start so that it showed visible indentation to separate itself from the paragraph content, but wouldn't be covered by the sticky heading Layered above other nearly content, set to a z-index of 10 (layer-raised) Returns to normal flow and default margin below 52rem Browser tests at various viewport sizes to show indentation, proper layering and no overflow
.story-guide Navigation aid for the main content Appears as a sidebar in the normal flow, and becomes sticky when scrolling in both small and large viewports Used a sticky positioning to keep it visible while scrolling Set to a z-index of 20 (layer-sticky) within the main content area Continues to be sticky when viewport smaller than 52rem, scroll-margin-block-start set to 11rem to adjust for the smaller viewports Browser tests at various viewport sizes to show sticky behavior and proper layering
.feature-figure (clip path) Displays mean feature image for the page Would display as a rectangular image Used a polygon clip-path to create a custom shape for the feature figure Has no stacking context, therefore has default layering @supports allow image fallback Browser tests to verify image displays as intended
.feature-figure (border radius) Displays mean feature image for the page Would display as a rectangular image Adjusted border radius for a more squared-off appearance to match the sharper edges of the clip-path, still maintains a slightly rounded edge Has no stacking context, therefore has default layering @supports allow image fallback Browser tests to verify image displays as intended
.feature-header Holds article title, sub--title and badge Stacks vertically by default position: relative to act as an anchor for the badge, which is set to position: absolute It is the containing block for the badge Remains in normal flow Browser tests to verify header displays as intended at various viewport sizes
.shape-portrait Provides an image alongside the concluding paragraph Would display as a rectangular image shape-outside:circle, float and shape-margin, provides a circular margin around image for text to wrap around Contributes to the layout's text flow Would fallback to a rectangular image in normal flow for browsers that don't support shape-outside Browser tests to verify image displays as intended at various viewport sizes
